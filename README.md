# Vintage-Record-Player

## Project Description

A personal project focused on developing a vintage-inspired record player with Spotify integration. The aim is to create an interactive interface that recreates the experience of using a traditional record player while allowing music playback through Spotify's API.

Currently in the early stages of development, this project is an opportunity to explore new technologies and strengthen my skills in frontend development, API integration, and UI/UX design. The final application format and additional features are still being explored as I continue to learn and develop the project.

**Status**: Work in Progress

## Key Features

- *Vintage Record Player Interface*: An interactive, vintage-inspired record player with a realistic design.
- *Spotify Integration*: Connect to Spotify through its API to access and play music.
- *Music Playback Controls*: Play, pause, skip, and control music directly through the record player.
- *Interactive Animations*: Animated vinyl records and turntable components that respond to music playback.
- *Track Information*: Display the currently playing song, artist, and album artwork.
- *Web/Desktop Application*: Create an accessible music player for use on a computer, with the final platform yet to be decided.


## Learning Goals

This project is an opportunity to explore new technologies, improve my programming skills, and gain practical experience building an application from the ground up.

Some of the main areas I aim to learn and develop throughout this project include:

- *Frontend Development:* Improve my understanding of HTML, CSS, JavaScript, and potentially TypeScript while building an interactive and responsive user interface.
- *API Integration:* Learn how to work with third-party APIs, particularly the Spotify Web API, to retrieve music data and integrate Spotify functionality.
- *UI/UX Design:* Explore interface design, animations, and user interactions to create an engaging vintage record player experience.
- *State Management:* Learn how to manage application state, including playback status, selected tracks, and user interactions.
- *Testing & Debugging:* Gain experience identifying issues, debugging code, handling errors, and writing tests to improve reliability.

As the project progresses, I hope to expand these goals and explore additional features and technologies.
